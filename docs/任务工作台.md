# 任务工作台使用指南

任务工作台是 caldav-free 内置的滴答清单风格任务管理界面，入口：

```text
http://<host>:5232/admin/tasks
```

它和 CalDAV 客户端共享同一批 `VTODO` 数据：工作台修改会写入 CalDAV，客户端修改会在下次打开工作台时回写。

## 1. 界面结构

| 区域 | 说明 |
| --- | --- |
| 图标栏 | 清单、看板、日历、统计、AI、搜索、主题、管理后台 |
| 侧栏 | 智能视图、清单/文件夹、保存过滤器、标签、账户 |
| 主区域 | 任务列表 / 看板 / 日历 / 统计 / AI |
| 右侧详情 | 任务标题、备注、日期、重复、提醒、标签、子任务、优先级 |

移动端：侧栏变为抽屉，任务详情变为全屏面板。

## 2. 智能视图

| 视图 | 说明 |
| --- | --- |
| 所有 | 未完成任务 + 最近完成 |
| 今天 | 今天到期 + 已逾期未完成 |
| 最近 7 天 | 今天起 7 天内到期 |
| 收集箱 | 收集箱内任务 |
| 已完成 | 已完成任务 |
| 垃圾桶 | 软删除任务，可恢复或彻底删除 |
| 统计 | 任务统计页 |
| AI 助手 | 对话式任务管理 |

支持按标签点击筛选，按标题/备注关键词搜索。

## 3. 快速添加与自然语言

输入框支持自然语言，回车创建。示例：

```text
明天下午 3 点和张三开会 #工作 !!
下周一 10 点提交周报
周五 写周报
10 月 25 日 买生日礼物
15:30 打电话
今晚 8 点跑步 #健康
```

解析规则：

- 日期：今天、明天、后天、大后天、今晚、明晚、周一…周日、本周一、下周一、N 月 N 日、YYYY-MM-DD
- 时间：`下午 3 点`、`15:30`、`3 点半`、`晚上 8 点`
- 只有日期没有时间 → 全天任务
- 没有日期只有时间 → 今天
- 标签：`#工作`
- 优先级：`!` = 低、`!!` = 中、`!!!` = 高
- 没有指定清单时添加到收集箱；在某个清单视图内添加时加入当前清单

解析使用浏览器时区；服务端“今天/最近 7 天”边界使用 `Asia/Shanghai`。

## 4. 任务字段

| 字段 | 说明 |
| --- | --- |
| 标题 | 必填 |
| 备注 | 纯文本，自动保存 |
| 日期 | 定时或全天 |
| 重复 | 每天、工作日、每周、每月、每年、自定义 RRULE |
| 提醒 | 准时、提前 5 分钟、15 分钟、1 小时、1 天 |
| 优先级 | 0 无、1 低、2 中、3 高 |
| 标签 | 最多 20 个，自动去重 |
| 子任务 | checklist 列表，支持完成状态 |
| 清单 | 可移动到其他清单 |

详情面板输入后约 500ms 自动保存，底部显示“已保存”/“保存中”。

## 5. 重复任务

预设：

- 每天：`FREQ=DAILY`
- 工作日：`FREQ=WEEKLY;BYDAY=MO,TU,WE,TH,FR`
- 每周：`FREQ=WEEKLY`
- 每月：`FREQ=MONTHLY`
- 每年：`FREQ=YEARLY`
- 自定义：输入标准 RRULE，例如 `FREQ=MONTHLY;BYMONTHDAY=15`

完成行为：

- 有到期时间的重复任务完成后，不归档，而是把 `DTSTART` / `DUE` 推进到下一次
- 无到期时间的重复任务按普通任务完成
- 带 `COUNT` / `UNTIL` 的规则会以当前到期时间重新锚定
- 不保留每次完成的历史实例

## 6. 提醒

相对提醒：

| 选项 | 偏移 |
| --- | --- |
| 不提醒 | `-1` |
| 准时 | `0` |
| 提前 5 分钟 | `5` |
| 提前 15 分钟 | `15` |
| 提前 1 小时 | `60` |
| 提前 1 天 | `1440` |

两种投递方式：

1. **CalDAV `VALARM`**：写入 VTODO，支持提醒的客户端会触发。
2. **浏览器通知**：点击图标栏铃铛开启，需要 HTTPS 或 localhost，并且页面保持打开；每 30 秒检查一次。

浏览器通知依赖 `Notification` API，手机浏览器可能不支持或需要在系统设置中授权。

## 7. 清单、文件夹、标签

### 清单

- 每个用户自动拥有“收集箱”
- 清单支持名称、颜色、所属文件夹
- 删除清单时，任务移动到收集箱
- `caldav-tasks` 是自动维护的任务同步日历，管理后台不能删除

### 文件夹

- 侧栏“清单”区域可新建文件夹
- 清单可归入文件夹，文件夹可折叠
- 删除文件夹只解除归类，不删除清单
- 文件夹暂不支持拖拽排序

### 标签

- 在任务里输入 `#标签`
- 侧栏显示标签云，可点击筛选
- 标签管理支持重命名、删除，显示使用次数
- 重命名/删除会更新所有任务、VTODO `CATEGORIES` 和保存过滤器条件
- 标签暂不支持颜色

## 8. 保存过滤器

条件：

| 条件 | 取值 |
| --- | --- |
| 清单 | 多选 |
| 标签 | 多选，任一 / 全部 |
| 优先级 | 高 / 中 / 低 |
| 状态 | 未完成 / 已完成 / 全部 |
| 日期 | 不限 / 今天 / 最近 7 天 / 已逾期 / 无日期 |
| 关键词 | 标题或备注 |

特性：

- 命名保存，显示在侧栏“过滤器”
- 支持编辑、删除
- 点击应用，URL 形如 `/admin/tasks?view=filter&filter=1`
- 删除清单时自动从条件中移除该清单
- 重命名/删除标签时自动更新条件

## 9. 垃圾桶、批量操作、手动排序

### 垃圾桶

- 删除任务进入垃圾桶
- 支持单条恢复、单条彻底删除、清空垃圾桶
- 恢复时如果原清单不存在，自动回到收集箱
- 恢复会重新生成 VTODO 身份并推送

### 批量操作

工具栏“多选”：

- 批量完成
- 批量移动到清单
- 批量删除
- 批量完成重复任务同样会推进到下一次

### 手动排序

工具栏排序按钮：

- 关闭时按到期时间分组
- 开启后显示可拖拽列表，拖动保存顺序
- 顺序写入 `order_index`
- 只保证当前筛选结果内的相对顺序

## 10. 日历

日历模式支持四种视图：

| 视图 | 说明 |
| --- | --- |
| 月 | 任务与 CalDAV 事件同屏；全天事件按天展开 |
| 周 | 7 天时间网格、全天区域、当前时间线 |
| 日 | 单日时间网格 |
| 日程 | 未来 30 天按日期分组清单 |

功能：

- 任务使用清单颜色，事件使用日历颜色
- 顶部图例显示日历与任务
- 点击任务打开任务详情
- 点击事件跳转到管理后台事件编辑页
- 点击日期打开当日安排面板，可快速添加任务
- 重复 `VEVENT` 会展开为多个实例
- 时间网格自动滚动到 07:00
- 重叠日程自动分列

事件来源：

- 当前用户全部 CalDAV 日历
- 排除 `caldav-tasks` 任务同步日历
- 单次查询最多 120 天、2000 个实例

## 11. 统计

入口：`/admin/tasks?view=stats`

周期：7 / 30 / 90 天。

内容：

- 未完成、已完成、已逾期、完成率
- 每日新建柱状图、完成柱状图、到期折线
- 环形完成率、按时完成数量
- 按清单分布（点击进入清单）
- 按优先级分布
- 按标签分布（点击筛选标签）
- 周期概览：新建、完成、到期、按时完成、平均完成耗时、垃圾桶

统计只基于仍保留的任务；彻底删除或清空垃圾桶会移除历史。

## 12. 摘要

入口：侧栏“摘要”或 `/admin/tasks?view=summary`

摘要页把筛选出的任务生成成一份可编辑文档：

- 日期范围：今天、明天、昨天、本周、下周、上周、本月、上月、自定义
- 清单：全部或指定清单
- 状态：全部、已完成、未完成
- 优先级、标签
- 分组：按完成状态、清单、完成时间、任务时间、标签、优先级
- 显示内容：完成时间、任务时间、标签、所属清单、优先级、详细内容
- 下一周期任务：追加当前范围之后同等长度时间段内到期的未完成任务
- 内容优化（AI）：调用已配置模型把摘要重写为更简洁的 Markdown 文档；未配置模型时开关不可用
- 默认生成“已完成 / 未完成”分组，已完成项显示 `[M月D日] 标题`

编辑与导出：

- 富文本工具栏：标题、加粗、高亮、复选框、无序/有序列表、缩进、斜体、下划线、删除线、颜色、链接、代码、引用
- 复制：写入剪贴板（HTML + 纯文本）
- 保存为：保存到历史、导出 HTML、打印/PDF、发送邮件
- “模板”：把当前摘要保存到服务端，跨设备可用
- 顶部文档图标：查看服务端历史文档

限制：

- 模板与历史文档正文以原始 HTML 保存，最多 300KB
- 图片导出未实现
- AI 内容优化会替换当前编辑内容，不能与手工排版合并
- 不支持指派人、进度、专注数据等字段
- 富文本为浏览器 execCommand 基础能力

## 13. AI 助手

入口：图标栏 AI 或 `/admin/tasks?view=ai`

### 配置

页面“AI 设置”：

- Base URL
- 模型名称
- API Key（保存后不回传）
- 清除已保存 Key

环境变量：

```bash
CALDAV_AI_BASE_URL=https://api.openai.com/v1
CALDAV_AI_MODEL=gpt-4o-mini
CALDAV_AI_API_KEY=sk-...
```

支持 OpenAI 兼容 Chat Completions，并要求支持 tools/function calling。

示例：

| 服务 | Base URL | 模型 |
| --- | --- | --- |
| OpenAI | `https://api.openai.com/v1` | `gpt-4o-mini` |
| DeepSeek | `https://api.deepseek.com/v1` | `deepseek-chat` |
| Ollama | `http://127.0.0.1:11434/v1` | 本地模型名 |

### 工具能力

- `list_lists`：列出清单
- `list_tasks`：按视图/清单/关键词查询
- `get_stats`：最近 30 天统计
- `create_task`：创建任务
- `update_task`：修改任务、移动清单
- `complete_task`：完成任务
- `delete_task`：移入垃圾桶
- `create_list`：创建清单

AI 修改后工作台自动刷新。

### 语音输入

- 使用浏览器 Web Speech API
- 中文识别
- 需要麦克风权限，通常需要 HTTPS 或 localhost

### 隐私

- 对话、任务、清单、统计会发送到配置的模型服务
- API Key 明文保存在本地 SQLite，仅管理员可读
- 对话记录保存在浏览器 localStorage，不写入服务端
- 删除等破坏性操作依赖模型遵循系统提示，建议人工核对

## 14. CalDAV VTODO 同步

每个用户自动创建：

```text
/calendars/<用户名>/caldav-tasks/
```

字段映射：

| 工作台 | VTODO |
| --- | --- |
| 标题 | `SUMMARY` |
| 备注 | `DESCRIPTION` |
| 日期 | `DUE`（DATE/DATE-TIME） |
| 重复 | `DTSTART` + `RRULE` |
| 优先级 | `PRIORITY`（高 1、中 5、低 9） |
| 完成 | `STATUS:COMPLETED`、`COMPLETED`、`PERCENT-COMPLETE` |
| 标签 | `CATEGORIES` |
| 子任务 | `X-CALDDAV-CHECKLIST` |
| 清单 | `X-CALDDAV-LIST` |
| 提醒 | `VALARM` + `TRIGGER` |

同步模型：

- 工作台创建/修改/完成/删除 → 立即写入/删除 VTODO
- 打开工作台时对账：
  - 导入客户端新建任务
  - 导入客户端修改
  - 识别客户端删除（墓碑）
  - 任务日历被删除时重建并恢复任务
- 冲突策略：工作台最后写入优先
- 任务日历被错误删除后，下次打开工作台会重建

客户端接入：把 `caldav-tasks` 日历添加到 Apple 提醒事项、DAVx5、Thunderbird 等支持 VTODO 的客户端。

## 18. 已知限制

- 提醒依赖页面打开或 CalDAV 客户端 `VALARM`，没有服务端推送调度器。
- 重复任务不保留每次完成历史。
- `COUNT` / `UNTIL` 复杂规则会重新锚定。
- 客户端写入的绝对时间 `VALARM` 不会转换为相对提醒。
- 多日定时事件只在开始日显示，不拆分跨天片段。
- 日历事件在工作台内只读，不支持拖拽改期。
- 日历图例不能点击隐藏日历。
- 子任务依赖 `X-CALDDAV-CHECKLIST`，少数客户端可能丢弃扩展属性。
- 所有任务清单共用一个 `caldav-tasks` 日历。
- 标签无颜色；文件夹/清单不支持拖拽排序。
- 任务工作台仅管理员可用。
- AI 非流式、无录音转写、无 MCP/CLI。
- 统计不含习惯、番茄、事件时长。
- 任务列表接口有分页上限，暂无无限滚动。

## 19. 排查

### AI 提示未配置

- 打开 AI 设置填写 Base URL 和模型
- 检查模型服务是否支持 tools/function calling
- 本地接口确认端口和 `/v1` 路径

### 浏览器提醒不生效

- 使用 HTTPS 或 localhost
- 浏览器允许通知
- 页面保持打开
- 系统勿扰模式可能拦截

### CalDAV 客户端看不到任务

- 确认客户端订阅了 `caldav-tasks` 日历
- 客户端需要支持 VTODO
- 打开一次工作台触发同步
- 检查 `caldav-tasks` 日历是否被删除

### 任务更新没有同步

- 打开任务工作台触发对账
- 查看服务端日志中的 `sync task workspace` / `push task to caldav`
- 确认任务日历存在并支持 VTODO
