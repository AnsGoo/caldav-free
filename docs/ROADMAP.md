## 3. 建议优先级

1. **提醒增强：稍后提醒/贪睡、微信/App 推送**
2. **协作共享：评论编辑、附件、协作动态**
3. **真实子任务 + 附件/评论**
4. **全天日程时长拖拽、动态实时刷新**
5. **AI 流式输出 + MCP + 删除确认**
6. **习惯 / 番茄 / 倒数纪念日**
7. **导入导出 + 普通用户自助空间**
8. **工程化：分页、冲突合并、Key 加密、审计**

## 4. 产品原则

- 自托管优先，数据留在自己的 SQLite。
- 标准优先：任务与事件尽量使用 CalDAV/VTODO/VEVENT 表达。
- 管理后台只对管理员开放，普通用户通过 CalDAV 客户端接入。
- AI 是可选能力，未配置不影响核心功能。
- 不使用外部托管依赖作为正常运行前提。
