# 任务工作台使用指南

任务工作台是 caldav-free 内置的滴答清单风格任务管理界面，入口：

```text
http://<host>:5232/admin/tasks
```

它和 CalDAV 客户端共享同一批 `VTODO` 数据：工作台修改会写入 CalDAV，客户端修改会在下次打开工作台时回写。

工作台各视图使用独立路径而不是统一查询参数：

| 路径 | 视图 |
| --- | --- |
| `/tasks` | 所有任务 |
| `/tasks/today` | 今天 |
| `/tasks/next7` | 最近 7 天 |
| `/tasks/inbox` | 收集箱 |
| `/tasks/completed` | 已完成 |
| `/tasks/trash` | 垃圾桶 |
| `/tasks/matrix` | 四象限 |
| `/tasks/habit` | 习惯 |
| `/tasks/stats` | 统计 |
| `/tasks/summary` | 摘要 |
| `/tasks/ai` | AI 助手 |
| `/tasks/calendar` | 日历 |
| `/tasks/board` | 看板 |
| `/tasks/list/:id` | 指定清单 |
| `/tasks/filter/:id` | 保存过滤器 |
| `/tasks/shared/:id` | 共享清单 |

旧版 `/tasks?view=matrix` 链接仍可打开，并会自动规范到新路径。`task`、`q`、`calendar`、`event` 等详情/搜索参数保留为查询参数。

## 1. 界面结构

| 区域 | 说明 |
| --- | --- |
| 图标栏 | 清单、看板、日历、四象限、统计、AI、搜索、主题、管理后台 |
| 侧栏 | 智能视图、清单/文件夹、保存过滤器、标签、账户 |
| 主区域 | 任务列表 / 看板 / 日历 / 四象限 / 统计 / AI |
| 右侧详情 | 任务标题、备注、日期、重复、提醒、标签、子任务、优先级 |

移动端：侧栏变为抽屉，任务详情变为全屏面板。

主内容区不再限制在 840px 阅读列：

- 清单、已完成、垃圾桶、统计、摘要、AI 助手使用主区域全部宽度
- 看板列按数量自适应铺满宽度，列内任务区独立纵向滚动
- 摘要与 AI 助手占满标题下方剩余高度
- 日历使用满宽满高画布
- 四象限、习惯、专注、倒数纪念日是独立全屏布局
- 960px 以下自动回退为自然高度和横向看板滚动，避免内容被压扁

## 2. 智能视图

| 视图 | 说明 |
| --- | --- |
| 所有 | 未完成任务 + 最近完成 |
| 今天 | 今天到期 + 已逾期未完成 |
| 最近 7 天 | 今天起 7 天内到期 |
| 收集箱 | 收集箱内任务 |
| 已完成 | 已完成任务 |
| 垃圾桶 | 软删除任务，可恢复或彻底删除 |
| 统计 | 任务统计页 |
| AI 助手 | 对话式任务管理 |

支持按标签点击筛选，按标题/备注关键词搜索。

### 四象限

入口：图标栏四宫格，URL `?view=matrix`。

页面顶部可切换、新建；齿轮按钮打开“管理四象限视图”，支持重命名、拖拽排序、修改规则和删除。

默认简化规则按优先级分组：

| 象限 | 优先级 |
| --- | --- |
| 重要且紧急 | 高 |
| 重要不紧急 | 中 |
| 不重要但紧急 | 低 |
| 不重要不紧急 | 无 |

“优先级 + 日期”规则：

- 重要：高/中优先级
- 紧急：已过期、今天或明天到期
- 其他任务进入不紧急象限

自定义规则模式下，每个象限可以包含多个条件组：

- 条件组内部各字段为“且”
- 条件组之间可选择“满足全部条件组”或“满足任一条件组”
- 空白条件组会匹配全部任务
- 每个象限最多 12 个条件组
- 多条件组可通过左侧拖拽手柄排序
- 象限标题和条件组标题实时显示当前规则下的命中数量

每个条件组可设置：

| 条件 | 可选值 |
| --- | --- |
| 优先级 | 高 / 中 / 低 / 无，可多选；不选为任意 |
| 日期 | 任意 / 紧急（逾期、今天、明天）/ 已过期 / 今天 / 明天 / 未来 7 天 / 7 天以后 / 无日期 |
| 清单 | 任意或指定清单 |
| 标签 | 任意或指定标签 |
| 指派人 | 任意或指定成员 |

例如“重要且紧急”设置两个条件组并选择“满足任一条件组”：

```text
组 1：优先级 = 高 AND 日期 = 紧急
组 2：标签 = 紧急
```

这样“高优先级且紧急”或“带紧急标签”的任务都会进入该象限。

规则弹窗顶部提供内置模板：

- 按优先级分组
- 优先级 + 日期
- 清空全部条件

模板只替换条件组，不覆盖象限名称和颜色。每个象限底部还支持“复制条件 / 粘贴条件”，可把一个象限的条件组整体复制到另一个象限。

“套用模板”下拉还支持用户模板：

- 点击“保存为模板”，输入名称后把当前四个象限的完整规则、名称和颜色保存到服务端
- 自定义模板出现在“我的模板”分组中，可跨设备复用
- 选择模板后会覆盖当前规则、象限名称和颜色
- 选中自定义模板后会出现“当前模板”操作条：
  - 修改名称并点击「重命名」
  - 点击「更新规则」用当前四象限规则覆盖模板
  - 「删除」第一次点击进入确认状态，第二次真正删除

每个象限还可以设置名称和颜色，保存后随视图生效；切换“按优先级”或“优先级 + 日期”模式时仍保留这些显示设置。

匹配顺序为 Q1 → Q2 → Q3 → Q4，未匹配任何条件的任务自动归入“不重要不紧急”。点击顶部漏斗按钮可编辑当前视图的自定义规则；切换到其他规则模式不会丢失已保存的自定义条件。

简化模式下可拖动任务到其他象限，自动修改为对应的优先级（高/中/低/无）。

自定义模式下也可以直接拖动任务到目标象限。系统会按目标象限的条件组生成任务补丁：

- 优先级：取条件组中的最高值
- 日期：按今天、明天、紧急、未来 7 天、7 天以后、已过期、无日期生成对应日期
- 清单、标签、指派人：按条件组补齐
- 多条件组时先尝试合并；“满足任一条件组”会依次尝试各组

补丁会先在内存中验证任务是否真的会落入目标象限，验证通过后才调用任务更新接口。若条件组互相冲突无法满足，会提示并保持任务不变。

每个象限右上角可折叠/展开，折叠状态按视图保存在浏览器本地。

顶部「多选」开启后，点击任务行可勾选任务；批量操作条会把选中任务按目标象限规则调整条件并移动。

每个象限标题右侧的加号可展开快速添加输入框，新任务会按该象限当前规则自动设置优先级、日期、清单、标签和指派人。自定义规则无法自动满足时会提示并取消创建。

顶部「手动排序」开启后：

- 每个象限不再按日期分组，而是一个连续列表
- 拖动任务调整象限内顺序，顺序保存到任务的全局 `order`
- 拖到其他象限的任务行或卡片上时，会先按目标象限规则调整任务条件，再插入到目标位置
- 排序会同步到其他使用手动排序的列表视图
- 关闭后恢复无日期/已过期/今天/明天/未来/已完成分组

视图和规则保存在服务端，换设备后仍可恢复。

每个象限内按状态分组：

- 无日期
- 已过期
- 今天
- 明天
- 未来
- 已完成

页面顶部可切换是否显示已完成任务，选择会保存在浏览器本地。隐藏后四象限数量、分组和规则弹窗命中预览都会排除已完成任务。

点击任务打开详情；点击圆圈可直接完成/取消完成。页面隐藏清单侧栏和列表工具栏，保留图标栏与任务详情。

## 3. 快速添加与自然语言

输入框支持自然语言，回车创建。示例：

```text
明天下午 3 点和张三开会 #工作 !!
下周一 10 点提交周报
周五 写周报
10 月 25 日 买生日礼物
15:30 打电话
今晚 8 点跑步 #健康
```

解析规则：

- 日期：今天、明天、后天、大后天、今晚、明晚、周一…周日、本周一、下周一、N 月 N 日、YYYY-MM-DD
- 时间：`下午 3 点`、`15:30`、`3 点半`、`晚上 8 点`
- 只有日期没有时间 → 全天任务
- 没有日期只有时间 → 今天
- 标签：`#工作`
- 优先级：`!` = 低、`!!` = 中、`!!!` = 高
- 没有指定清单时添加到收集箱；在某个清单视图内添加时加入当前清单

解析使用浏览器时区；服务端“今天/最近 7 天”边界使用 `Asia/Shanghai`。

## 4. 任务字段

- 开始日期 / 时间
- 截止日期 / 时间
- 时长由开始与截止时间自动计算
- 全天任务复用同一 `allDay` 标记
- CalDAV VTODO 同时写入 `DTSTART` 与 `DUE`


| 字段 | 说明 |
| --- | --- |
| 标题 | 必填 |
| 备注 | 纯文本，自动保存 |
| 日期 | 定时或全天 |
| 重复 | 每天、工作日、每周、每月、每年、自定义 RRULE |
| 提醒 | 准时、提前 5 分钟、15 分钟、1 小时、1 天；一个任务最多 10 个 |
| 优先级 | 0 无、1 低、2 中、3 高 |
| 标签 | 最多 20 个，自动去重 |
| 子任务 | checklist 列表，支持完成状态 |
| 清单 | 可移动到其他清单 |
| 指派人 | 清单所有者或共享成员；仅共享协作时显示 |

详情面板输入后约 500ms 自动保存，底部显示“已保存”/“保存中”。

## 5. 子任务与附件

- 任务详情中的「子任务」使用真实任务层级 `parentId`，不是 checklist 扩展字段
- 父任务可以添加、完成、打开和删除子任务；完成或删除父任务会同步处理子任务
- 子任务在任务列表中缩进显示
- 「检查项」继续使用 `X-CALDDAV-CHECKLIST`，与真实子任务并存
- 任务附件支持图片和其他文件，单文件 10MB，存储于 SQLite `task_attachments`
- 图片附件可直接预览，其他附件可下载；附件删除受任务权限控制

## 6. 重复任务

预设：

- 每天：`FREQ=DAILY`
- 工作日：`FREQ=WEEKLY;BYDAY=MO,TU,WE,TH,FR`
- 每周：`FREQ=WEEKLY`
- 每月：`FREQ=MONTHLY`
- 每年：`FREQ=YEARLY`
- 自定义：输入标准 RRULE，例如 `FREQ=MONTHLY;BYMONTHDAY=15`

完成行为：

- 有到期时间的重复任务完成后，不归档，而是把 `DTSTART` / `DUE` 推进到下一次
- 无到期时间的重复任务按普通任务完成
- 带 `COUNT` / `UNTIL` 的规则会以当前到期时间重新锚定
- 不保留每次完成的历史实例

## 7. 任务模板

- 任务详情右上角复制图标可保存当前任务为模板
- 快速添加栏右侧模板图标打开模板列表
- 点击模板即可创建任务
- 模板保存标题、备注、清单、优先级、标签、子任务、重复规则和提醒偏移
- 模板不保存到期日期，创建后再设置日期
- 模板保存在 SQLite，可跨设备使用；模板列表支持删除

## 8. 提醒

一个任务可以设置多个提醒，最多 10 个。详情面板“提醒”区域可逐行添加/删除；每个提醒独立计算触发时刻。

相对提醒：

| 选项 | 偏移 |
| --- | --- |
| 不提醒 | `-1` |
| 准时 | `0` |
| 提前 5 分钟 | `5` |
| 提前 15 分钟 | `15` |
| 提前 1 小时 | `60` |
| 提前 1 天 | `1440` |

每个提醒都会单独生成 CalDAV `VALARM`，服务端也按提醒偏移分别投递。四种投递方式：

1. **CalDAV `VALARM`**：写入 VTODO，支持提醒的客户端会触发。
2. **页面内浏览器通知**：点击图标栏铃铛打开“提醒设置”，开启后每 30 秒检查一次；需要 HTTPS 或 localhost，并且页面保持打开。
3. **服务端 Web Push**：在“提醒设置”中点击“开启后台推送”，浏览器会向推送服务注册订阅，服务端调度器在提醒时刻投递。页面关闭后仍可收到，但浏览器需要保持运行。
4. **邮件提醒**：在“提醒设置”中配置 SMTP 并启用，服务端会把提醒发送到当前账号邮箱；可点击“发送测试邮件”验证配置。

服务端调度器每 30 秒检查一次，默认只补发最近 6 小时内到期的提醒；成功记录写入 `reminder_deliveries`，同一任务、同一到期时间、同一提醒偏移、同一通道只发送一次。失败投递写入 `reminder_attempts`，按 1 分钟、2 分钟、4 分钟…最长 2 小时退避重试。浏览器完全退出时，推送可能延迟到下次启动。

多提醒会按各自偏移分别去重；修改到期时间后，所有提醒的键都会变化并重新计算。

任务提醒也会写入站内通知，可在通知中心直接完成任务或选择稍后提醒。通知中心支持全部 / 未读 / 任务 / 日程筛选。

工作台通过 SSE 连接 `/api/admin/notifications/stream`，新通知会立即更新未读角标；仍保留 60 秒轮询作为兜底。

配置：

| 环境变量 | 默认值 | 说明 |
| --- | --- | --- |
| `CALDAV_REMINDERS` | 开启 | 设为 `off` 关闭服务端调度器 |
| `CALDAV_REMINDER_INTERVAL` | `30s` | 检查间隔，最小 `10s` |
| `CALDAV_PUSH_SUBJECT` | `mailto:admin@example.com` | VAPID 联系人，建议改成真实邮箱或站点 URL |
| `CALDAV_SMTP_ENABLED` | `0` | 设为 `1` 启用邮件（页面保存后以页面配置为准） |
| `CALDAV_SMTP_HOST` | 空 | SMTP 服务器 |
| `CALDAV_SMTP_PORT` | `587` | SMTP 端口 |
| `CALDAV_SMTP_USER` | 空 | SMTP 用户名 |
| `CALDAV_SMTP_PASSWORD` | 空 | SMTP 密码或授权码 |
| `CALDAV_SMTP_FROM` | 空 | 发件人，缺省使用用户名 |
| `CALDAV_SMTP_SECURITY` | `starttls` | `starttls` / `tls` / `none` |

VAPID 密钥首次启动时自动生成并保存在 `settings` 表。SMTP 密码同样保存在 `settings`，接口只返回“是否已设置”，不会回传明文；建议使用应用专用授权码。

## 9. 清单、文件夹、标签

### 清单

- 每个用户自动拥有“收集箱”
- 清单支持名称、颜色、所属文件夹
- 删除清单时，任务移动到收集箱
- `caldav-tasks` 是自动维护的任务同步日历，管理后台不能删除

### 共享清单

- 清单行右侧的共享按钮打开成员管理
- 输入管理后台用户名并选择“只读”或“可编辑”
- 接收方侧栏出现“共享给我”，显示清单名、任务数、所有者和角色
- 只读成员看到只读详情，不能快速添加或完成/删除
- 编辑成员可以新建、修改、完成、删除和指派共享清单中的任务
- 任务详情“指派人”可在清单所有者和共享成员之间选择
- 任务行和详情顶部显示 `@用户名`
- 指派给其他成员时生成站内通知；侧栏“通知”显示未读角标
- 点击通知直接打开对应共享任务或清单任务
- 已启用 Web Push / SMTP 时，指派也会尝试发送后台通知和邮件
- 编辑者不能管理共享，也不能把任务移动到其他清单
- 所有者再次打开共享弹窗可直接下拉修改成员角色，或移除成员
- 接收方重新进入共享清单、切回页面或 60 秒内会自动刷新角色
- 收集箱不能共享

### 任务动态

任务详情“动态”区域记录：

- 创建任务
- 指派给成员
- 取消指派
- 完成或重新打开
- 重复任务完成本次
- 一次保存中修改标题、日期、优先级、标签、备注、重复规则、提醒或清单时，合并为一条“修改了…”动态
- 同一用户对同一任务的连续字段修改在 2 分钟内继续合并，避免自动保存刷屏

动态按时间倒序显示操作者和相对时间。评论、附件和 @提及在“评论”区域展示。

### 文件夹

- 侧栏“清单”区域可新建文件夹
- 清单可归入文件夹，文件夹可折叠
- 删除文件夹只解除归类，不删除清单
- 文件夹和同一文件夹内的清单支持拖拽排序，顺序写入服务端

### 标签

- 在任务里输入 `#标签`
- 侧栏显示标签云，可点击筛选
- 标签管理支持重命名、删除，显示使用次数
- 重命名/删除会更新所有任务、VTODO `CATEGORIES` 和保存过滤器条件
- 每个标签支持独立颜色，可在“管理标签”中通过色板设置
- 未设置颜色时按标签名生成稳定的默认颜色

## 10. 保存过滤器

条件：

| 条件 | 取值 |
| --- | --- |
| 清单 | 多选 |
| 标签 | 多选，任一 / 全部 |
| 优先级 | 高 / 中 / 低 |
| 状态 | 未完成 / 已完成 / 全部 |
| 日期 | 不限 / 今天 / 最近 7 天 / 已逾期 / 无日期 |
| 关键词 | 标题或备注 |

特性：

- 命名保存，显示在侧栏“过滤器”
- 支持编辑、删除
- 点击应用，URL 形如 `/admin/tasks?view=filter&filter=1`
- 删除清单时自动从条件中移除该清单
- 重命名/删除标签时自动更新条件

## 11. 垃圾桶、批量操作、手动排序

### 垃圾桶

- 删除任务进入垃圾桶
- 支持单条恢复、单条彻底删除、清空垃圾桶
- 恢复时如果原清单不存在，自动回到收集箱
- 恢复会重新生成 VTODO 身份并推送

### 批量操作

工具栏“多选”：

- 批量完成
- 批量移动到清单
- 批量删除
- 批量完成重复任务同样会推进到下一次

### 置顶

- 任务：行右侧图钉按钮或 `Tab+P`；置顶任务独立成「置顶」分组，取消后回到原日期分组
- 清单、过滤器：悬停右侧图钉按钮；置顶后进入侧栏顶部图标条，不再占用普通列表
- 置顶只保存在工作台，不写入 CalDAV VTODO

### 手动排序

工具栏排序按钮：

- 关闭时按到期时间分组
- 开启后显示可拖拽列表，拖动保存顺序
- 顺序写入 `order_index`
- 只保证当前筛选结果内的相对顺序

## 15. AI 助手

入口：图标栏 AI 或 `/tasks/ai`

### 配置

页面“AI 设置”：

- 服务商：OpenAI、DeepSeek、Moonshot、智谱 GLM、通义千问、SiliconFlow、Groq、OpenRouter、Ollama、自定义
- 选择服务商后自动填充 Base URL，可手动修改
- API Key（保存后不回传）
- 获取模型：使用当前 Base URL 和 Key 调用 `/models`，Ollama 会优先兼容原生 `/api/tags`
- 模型列表常驻显示，可按名称筛选，点击即可选中；支持手动填写
- 模型带推荐、工具调用、视觉、推理、轻量等推测标签，非对话模型会标红提示
- 「测试连接」发送最小对话请求并显示延迟
- 「测试工具调用」发送一个 ping 工具，验证模型是否会发起 function call
- 模型列表显示历史平均耗时
- 清除已保存 Key

环境变量：

```bash
CALDAV_AI_PROVIDER=openai
CALDAV_AI_BASE_URL=https://api.openai.com/v1
CALDAV_AI_MODEL=gpt-4o-mini
CALDAV_AI_API_KEY=sk-...
```

支持 OpenAI 兼容 Chat Completions，并要求支持 tools/function calling 和 stream 流式响应。回复通过 SSE 实时显示；模型决定调用工具时，工具执行期间继续显示“思考中”，执行完成后继续流式输出最终回复。

AI 对话顶部会显示已获取的模型下拉框，最近使用的模型排在“最近使用”分组，可只对当前对话切换模型；选择会保存在浏览器本地，不修改默认模型。

如果当前模型调用失败且尚未执行任何任务操作，会按顺序尝试默认模型、最近使用模型和已保存模型，最多尝试 3 个候选；成功后提示原因并把对话模型切换到可用模型。成功后最近使用列表和模型耗时统计会更新。

示例：

| 服务 | Base URL | 模型 |
| --- | --- | --- |
| OpenAI | `https://api.openai.com/v1` | `gpt-4o-mini` |
| DeepSeek | `https://api.deepseek.com/v1` | `deepseek-chat` |
| Ollama | `http://127.0.0.1:11434/v1` | 本地模型名 |

### 工具能力

- `list_lists`：列出清单
- `list_tasks`：按视图/清单/关键词查询
- `get_stats`：最近 30 天统计
- `create_task`：创建任务
- `update_task`：修改任务、移动清单
- `complete_task`：完成任务
- `delete_task`：移入垃圾桶
- `create_list`：创建清单

AI 修改后工作台自动刷新。

### 语音输入

- 使用浏览器 Web Speech API
- 中文识别
- 需要麦克风权限，通常需要 HTTPS 或 localhost

### 隐私

- 对话、任务、清单、统计会发送到配置的模型服务
- API Key 明文保存在本地 SQLite，仅管理员可读
- 对话记录保存在浏览器 localStorage，不写入服务端
- 删除等破坏性操作依赖模型遵循系统提示，建议人工核对

## 16. CalDAV VTODO 同步

每个用户自动创建：

```text
/calendars/<用户名>/caldav-tasks/
```

字段映射：

| 工作台 | VTODO |
| --- | --- |
| 标题 | `SUMMARY` |
| 备注 | `DESCRIPTION` |
| 日期 | `DUE`（DATE/DATE-TIME） |
| 重复 | `DTSTART` + `RRULE` |
| 优先级 | `PRIORITY`（高 1、中 5、低 9） |
| 完成 | `STATUS:COMPLETED`、`COMPLETED`、`PERCENT-COMPLETE` |

| 提醒 | `VALARM` + `TRIGGER` |

同步模型：

- 工作台创建/修改/完成/删除 → 立即写入/删除 VTODO
- 打开工作台时对账：
  - 导入客户端新建任务
  - 导入客户端修改
  - 识别客户端删除（墓碑）
  - 任务日历被删除时重建并恢复任务
- 冲突策略：工作台最后写入优先
- 任务日历被错误删除后，下次打开工作台会重建

客户端接入：把 `caldav-tasks` 日历添加到 Apple 提醒事项、DAVx5、Thunderbird 等支持 VTODO 的客户端。

## 20. 已知限制

- 页面内提醒依赖页面打开；服务端 Web Push 需要 HTTPS、通知权限和设备订阅，浏览器完全退出时可能延迟。
- 邮件提醒需要可用 SMTP，且当前账号必须有邮箱；SMTP 密码以明文保存在 SQLite。
- 重复任务不保留每次完成历史。
- `COUNT` / `UNTIL` 复杂规则会重新锚定。
- 客户端写入的绝对时间 `VALARM` 不会转换为相对提醒。
- 多日定时事件会按天拆分为多个片段，在月/周/日视图中分别显示。
- 工作台可新建/编辑/删除/拖拽改期日程；重复日程支持单次例外编辑和单次删除。
- 拖拽或调整时长对重复日程仍会修改整个系列。
- 日程可设置一个提前提醒（准时/5 分钟/15 分钟/1 小时/1 天），写入 `VALARM`
- 支持提醒的 CalDAV 客户端会按 `VALARM` 触发
- 工作台页面打开时会轮询并显示浏览器通知
- 服务端调度器会扫描日程 `VALARM`，按提醒时间向所有者写入站内通知，并发送 Web Push / SMTP 邮件
- 站内通知、推送和邮件链接包含日历 ID、ICS 文件名和实例开始时间，点击直接打开对应日程
- 日程通知可选择“10 分钟 / 30 分钟 / 1 小时 / 1 天”稍后提醒，服务端会重新生成站内通知并尝试推送/邮件
- 服务端日程提醒同样受 `CALDAV_REMINDERS` 开关和 SMTP/设备订阅配置影响
- 全天日程暂不支持拖动调整时长。
- 结构化日程编辑会重建标准字段，客户端写入的自定义属性/参与者可能丢失。
- 日历图例可点击隐藏/显示对应日历、任务或习惯。
- 子任务依赖 `X-CALDDAV-CHECKLIST`，少数客户端可能丢弃扩展属性。
- 所有任务清单共用一个 `caldav-tasks` 日历。
- 标签颜色只保存在工作台，不写入 CalDAV。
- 文件夹、清单、过滤器均支持拖拽排序；置顶项不在普通列表中拖动。
- 任务工作台仅管理员可用；清单共享也只在管理员账号之间生效。
- 清单共享支持 viewer/editor 和任务指派；站内、Web Push、邮件指派通知均已接入。
- 通知通过 SSE 实时更新，60 秒轮询作为兜底；浏览器/邮件通知依赖相应配置。
- 支持评论、编辑、@提及、附件和图片预览；暂不支持富文本、协作动态和共享过滤器。
- 指派人只保存在工作台，不写入 CalDAV VTODO。
- AI 已支持流式回复；无录音转写、无 MCP/CLI。
- 笔记只保存在工作台，不写入 CalDAV VTODO；笔记清单不支持切换成任务清单。
- 时间线只显示带开始或截止日期的任务；笔记、无日期任务不参与。
- 并列显示只支持「任务 + 日历」；打开任务详情时会暂时收起日历面板。
- 管理后台支持安装为 PWA；离线时只缓存应用外壳和静态资源，任务数据仍需网络。
- 统计不含习惯、番茄、事件时长。
- 任务列表接口有分页上限，暂无无限滚动。

## 21. 排查

### AI 提示未配置

- 打开 AI 设置填写 Base URL 和模型
- 检查模型服务是否支持 tools/function calling
- 本地接口确认端口和 `/v1` 路径

### 浏览器提醒不生效

- 使用 HTTPS 或 localhost
- 浏览器允许通知
- 页面内提醒需要页面保持打开
- 系统勿扰模式可能拦截

### 邮件提醒不生效

- 在“提醒设置”中确认已启用、服务器/端口/发件人正确
- 使用“发送测试邮件”查看具体 SMTP 错误
- 常见服务需要使用授权码而不是登录密码
- 端口 465 选 SSL/TLS，587 选 STARTTLS
- 检查当前账号邮箱是否为空
- 查看服务端日志中的 `email reminder` / `reminder retry scheduled`

### 后台推送不生效

- 确认站点使用 HTTPS（或 localhost），Service Worker 已注册
- 在“提醒设置”中确认本设备显示“已订阅”
- 检查 `CALDAV_PUSH_SUBJECT` 是否为真实邮箱或站点 URL
- 确认服务端未被 `CALDAV_REMINDERS=off` 关闭
- 查看服务端日志中的 `reminder scheduler` / `push reminder`
- 浏览器完全退出时通知可能延迟

### CalDAV 客户端看不到任务

- 确认客户端订阅了 `caldav-tasks` 日历
- 客户端需要支持 VTODO
- 打开一次工作台触发同步
- 检查 `caldav-tasks` 日历是否被删除

### 任务更新没有同步

- 打开任务工作台触发对账
- 查看服务端日志中的 `sync task workspace` / `push task to caldav`
- 确认任务日历存在并支持 VTODO
