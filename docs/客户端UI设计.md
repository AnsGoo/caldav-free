# Android 客户端视觉与交互规范

本文记录 2026-10 UI 重构后的设计语言。目标不是复制滴答清单，而是借鉴它「大留白、少边框、强层级」的处理方式，建立 caldav-free 自己的纸面式界面。

## 1. 设计原则

1. **纸面分层**：页面是一层层纸张，而不是一堆描边盒子。画布是浅灰，内容是白色圆角面。
2. **一个强调色**：蓝色只用于主操作、当前状态和关键数字；其他信息用墨色与灰色层级表达。
3. **大标题、小元信息**：每个主 Tab 用 30sp 左右的大标题建立入口，说明文字控制在 12sp，不抢视线。
4. **先留白，再分隔**：优先用间距和圆角分组；1px 分隔线只在列表内部使用。
5. **内容优先**：图标为线性 Material 图标，不使用 emoji 充当图标；重要数字使用粗体，次要文本降低对比。
6. **原生交互**：保留 Material 3 的底部导航、FAB、底部 Sheet、Snackbar、对话框和系统返回手势。

## 2. 颜色 Token

| Token | Light | Dark | 用途 |
|---|---|---|---|
| `AppColors.canvas` | `#F5F6F8` | `#0E1015` | 页面画布 |
| `AppColors.surface` | `#FFFFFF` | `#171A22` | 卡片、Sheet |
| `surfaceMuted` | `#F1F3F7` | `#20242E` | 输入框、未选 Chip |
| `primary` | `#3563F0` | `#7F9BFF` | 主操作、当前 Tab、关键数字 |
| `primaryContainer` | `#EAF0FF` | `#23335F` | 选中 Chip、图标底色 |
| `ink` | `#1B1F2A` | `#F2F4F8` | 主文本 |
| `inkSecondary` | `#656D7E` | `#9AA3B2` | 说明、元信息 |
| `line` | `#EDF0F5` | `#2A2F3A` | 列表分隔线 |
| `green` | `#2DCB8A` | 同左 | 完成、同步成功 |
| `orange` | `#FF9F43` | 同左 | 提醒、倒计时节日 |
| `red` | `#FF5C5C` | 同左 | 逾期、删除 |

`primary` 在白底上的对比度约为 5.0:1，`inkSecondary` 在画布上约为 4.8:1，满足小字号正文的可读性。

## 3. 字体层级

| 角色 | 字号/字重 | 典型用途 |
|---|---|---|
| Display | 48 / 300 | 番茄计时 |
| Headline | 30 / 800 | 任务、日历、习惯、专注、倒数日标题 |
| Title Large | 20 / 700 | Sheet 标题、分组标题 |
| Title Medium | 17 / 700 | 卡片标题 |
| Body Large | 16 / 500 | 任务标题、表单 |
| Body Small | 12.5 / 500 | 元信息、说明 |
| Label | 11–14 / 600 | Chip、Tab、状态 |

- 中文字体走系统字体（PingFang / Noto Sans CJK），避免自带字体包导致包体膨胀。
- 计时器使用 tabular figures，防止每秒跳动时数字宽度变化。
- 不通过斜体、全大写、渐变文字制造层级。

## 4. 形状与间距

- 页面左右边距：20dp；卡片内边距：14–16dp。
- 卡片圆角：20dp；Sheet 顶部圆角：28dp；输入框/按钮：14–16dp。
- FAB：56dp 圆形，右下 20dp。
- 卡片之间：8–12dp；分组之间：24dp。
- 底部导航：62dp 高，5 个 48dp 触控目标，图标 24dp，无文字标签。
- 所有触控目标 ≥48dp；底部导航、关闭按钮、更多菜单通过 `Semantics` 提供可访问名称。

## 5. 页面模式

### 任务

- 顶部：30sp 标题 + 小号同步状态。
- 视图切换：文字 Tab + 2dp 蓝色下划线，不使用分段按钮外框。
- 清单筛选：横向滚动胶囊；选中为浅蓝底，未选中透明。
- 任务卡：白色 18dp 圆角、无边框、24dp 圆形复选框；标题 15.5sp，元信息 12sp；优先级用 3dp 竖条。
- 快速添加：悬浮白色胶囊，带柔和阴影；右侧 40dp 蓝色发送按钮。
- 更多菜单：图标 + 文案，避免纯文字大菜单。

### 习惯

- 标题下直接显示「今天完成 n / m」。
- 所有习惯放在一张白色分组卡中，行间 1px 分隔；每行左侧 48dp 进度环 + 打卡按钮。
- 空状态使用浅蓝圆角图标 + 主标题 + 一句说明 + 主按钮。
- 编辑器使用底部 Sheet，字段为浅灰填充，主按钮固定底部。

### 专注

- 286dp 圆环，轨道 10dp，进度使用圆头弧线。
- 计时 58sp、300 字重，轨道与数字之间留出足够呼吸。
- 时长选择是三个文字胶囊；主按钮为 188×56 胶囊，重置为 52dp 圆形。
- 最近记录使用一张白色卡片，行间分隔线缩进到图标之后。

### 倒数日

- 卡片四角 20dp，白底无描边；左侧 50dp 淡色图标，右侧 34sp 数字。
- 未来显示「30 天」，今天显示「今天」，过去显示「30 天 / 前」。
- 图标使用 Material 线性/填充图标，不直接渲染 emoji。
- 颜色只用于图标底、数字和状态文字；数字颜色自动压暗保证对比度。

### 日历

- 大标题 + 单行视图 Tab；月份切换行保留左右箭头与「今天」。
- 月视图不画单元格边框，日期居中；今天用 32dp 蓝色圆，事件用最多 3 个 5dp 圆点。
- 日视图不再重复日期标题；无安排时使用空状态。
- 事件卡无左侧色条，改用 8dp 色点 + 标题 + 时间/清单元信息。

### 登录

- 画布式登录页，60dp 品牌图标 + 34sp 产品名。
- 表单放在一张白色圆角卡中，输入框浅灰填充，不使用描边。
- 主按钮 52dp，错误信息使用浅红底。

## 5.1 主题色系列

参考滴答清单 VIP 的「颜色系列」，提供 8 个经过对比度校准的强调色：

| 名称 | Hex | 白底对比度 |
|---|---|---|
| 经典蓝 | `#3563F0` | 5.0:1 |
| 湖水青 | `#2F7D8C` | 4.7:1 |
| 松柏绿 | `#1F7A4D` | 5.3:1 |
| 琥珀 | `#A85A12` | 5.1:1 |
| 玫瑰 | `#C23B5A` | 5.2:1 |
| 暮山紫 | `#6E4BD1` | 5.9:1 |
| 雾灰蓝 | `#4F637A` | 6.2:1 |
| 咖啡 | `#8A5A2B` | 5.9:1 |

- 主题色通过 `AppState.setAccent` 持久化到 `LocalStore`，重启后保留。
- 深色模式自动推导同色系浅色变体，主按钮文字按亮度切换深/浅。
- 入口：任务页右上角调色盘，或「更多 → 主题颜色」。
- 选择面板使用 52dp 色圆 + 名称 + 当前勾选，底部 Sheet 28dp 圆角。

## 5.2 日历视图

- 日历视图切换移到右上角菜单，避免 6 个 Tab 挤压：
  - 议程 / 年视图 / 月视图 / 周视图 / 3 日视图 / 日视图
- **3 日视图**：连续三天纵向分组，日期头 + 今日胶囊 + 当天条目数；每条日程/任务使用统一 `_EntryTile`。
- **年视图**：3 列 × 4 行迷你月历；今天实心圆，拥有事项的日期使用主题色加粗；点击日期进入日视图。
- 年视图按月分 4 段请求（每段 ≤ 92 天，服务端上限 120 天），合并事件、任务和来源。
- 月视图在日期下方显示文化标签：节日 > 节气 > 农历日；普通农历日灰色，节日/节气橙色。初一时显示农历月份，如「九月」。
- 标签来自 Basic Auth 农历接口，范围约 6 周；接口失败时回退到「节假日」事件标签。没有标签时保留固定高度，避免行跳动。
- 月视图仍使用无边框网格、今天实心圆和事件圆点；不在格子里堆叠事件标题。

## 6. 深色模式

- 深色不是简单反色：画布 `#0E1015`，卡片 `#171A22`，输入 `#20242E`。
- 主色提亮为 `#7F9BFF`，主按钮文字使用深色，保证按钮上的对比度。
- 圆环轨道、分割线、复选框边框在深色下单独调整，避免消失。
- 已在模拟器验证任务页与专注页深色模式。

## 7. 可访问性与适配

- 已验证系统字体缩放 1.3：标题、任务卡、底部导航不截断。
- 支持系统字体缩放和深色模式；后续补充平板 NavigationRail。
- 底部导航图标无文字，但提供 Tooltip 与 Semantics；这是有意的视觉选择。
- 输入框、按钮、菜单均使用 Material 3 状态层与焦点态。
- 空状态、加载、错误、禁用、删除确认均有对应界面。

## 8. 已知缺口

- 未引入自绘品牌插画；空状态暂时使用 Material 图标 + 色块。
- 尚未实现 Material You 动态取色；主题色目前是本机固定色板。
- 农历标签只显示日/月与节气，不显示宜忌、生肖和闰月详情。
- 年视图不显示农历标签；一次加载全年，数据量很大时仍需分页/缓存。
- 平板/折叠屏尚未使用 NavigationRail。
- 任务编辑器仍是全高 Sheet，后续可改为顶部详情卡 + 可展开字段。
