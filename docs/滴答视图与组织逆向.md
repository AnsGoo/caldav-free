# 滴答清单「视图与组织」逆向与可行性评估（实测版）

> 评估对象：`https://dida365.com/webapp`
> 首次评估：2026-10-24（仅静态 bundle）
> 登录态实测：2026-10-24（Pro 账号，有效期至 2026-11）
> 目的：判断 `docs/ROADMAP.md`「视图与组织」一节哪些能力值得做、怎么做、成本多少

---

## 0. 本次实测对上一版的修正

上一版只做静态 bundle 推断，登录后实测发现 5 处结论需要修正：

| 项目 | 上一版结论 | 实测结论 |
| --- | --- | --- |
| 命令面板 | 滴答没有命令面板 | **有**：`⌘/Ctrl + K` 打开「输入指令或搜索」，含新建任务、导航、帮助 |
| 过滤器置顶 | 滴答只有排序，没有置顶 | **有置顶**：右键过滤器 → 置顶，置顶后进入侧栏顶部图标条 |
| 清单置顶 | 只有任务置顶，无收藏 | **清单也有置顶**（右键 → 置顶）；仍无「收藏 / 星标」 |
| 主题数量 | 42 套 | 实测 **38 套**（颜色 12 + 城市 12 + 季节 4 + 摄影 10）+ 跟随系统 |
| 看板列 | 推断有颜色、状态 | 列只有 `id / projectId / name / sortOrder / etag`；**没有颜色和状态字段** |

另外确认：**跨筛选结果手动排序确实不支持**（过滤器排序只有时间/创建/修改/标题/标签/优先级 + 升降序）。

## 3. 逐项实测

### 3.1 时间线视图

**入口与形态**

- 与「清单 / 看板」并列的第三种视图；每个清单可设默认视图（新建清单弹窗「视图类型」三选一）。
- URL：`#q/all/timeline` / `#p/<projectId>/timeline`。
- 头部：`9月` + 「今天」+ 日期选择器；底部时间刻度按天。
- 左侧按清单分组（`收集箱`），任务条按开始/截止日期跨天绘制。
- 点击空白区域新建任务；按住空白拖动平移；支持 **日 / 周 / 月** 三档缩放。

**显示设置（实测）**

| 设置 | 选项 |
| --- | --- |
| 任务块颜色 | 无颜色 / 清单 / 标签 / 优先级 |
| 显示星期 | 开关 |
| 视图跨设备同步 | 开关（关闭后手机与电脑独立） |

**接口/配置**

- 清单对象带 `viewMode: "timeline"` 与 `timeline: {color, showWeek, showGuide, mtime}`。
- 偏好 `timelineTimeZones` 支持多时区（本次 UI 未暴露，可能按版本/订阅放开）。

**结论**：可做。我们已有 `StartAt / DueAt / AllDay / Priority / Tags`，新建 `TaskTimeline.vue` 即可；缩放、着色、拖拽改期都能复用日历逻辑。

### 3.2 看板自定义列

**实测流程**

1. 新建清单时选「看板」，自动生成「未分组」列。
2. 右上角「+ 新分组」直接内联命名创建。
3. 列头 `+`（新建任务）、`…` 菜单：重命名 / 在左侧添加分组 / 在右侧添加分组 / 移动到 / 删除。
4. 删除分组的文案区分两种策略：删除任务，或把任务移动到其他分组。
5. 列数量有上限（`column_limit_warn`）。
6. 看板显示设置：日期显示为（任务时间 / 倒数目）、看板尺寸（中）、显示添加输入框、视图跨设备同步。

**接口结构（实测）**

```json
[
  {
    "id": "…",
    "projectId": "…",
    "name": "进行中",
    "sortOrder": 1099511627776,
    "createdTime": "…",
    "modifiedTime": "…",
    "etag": "…"
  }
]
```

- 列**没有**颜色、状态、WIP 上限字段。
- 任务通过 `columnId` 归属列；任务还有 `progress`（0–100）。
- 任务右键菜单提供「放弃 / 重新开始」，即任务有「已放弃」状态。
- 清单对象带 `viewMode: "kanban"`。

**工作流看板**

- 语言包存在「普通看板 / 工作流看板」文案，但无入口可实测。
- 推断：工作流看板把「列」映射到任务状态，需要状态机；普通看板只是清单内二次分组。

**结论**：普通看板可做，但比上一版估计**更简单**（列只是命名桶）。工作流看板需单独立项并先确认产品形态。

### 3.3 笔记视图

**实测**

- 新建清单时可选择「清单类型：任务清单 / 笔记清单」。
- 笔记清单的空状态：「没有笔记 / 在这里记录灵感与时光」；顶部「添加笔记」。
- 笔记详情：标题 + 正文 +「记录你的想法，或 使用模板」；底部工具栏含文本样式、图片、更多。
- 笔记**没有日期/完成态**，在任务视图里不参与「今天/最近7天」。
- 笔记不支持拖拽（语言包 `cant_drag_notes`）。
- 笔记可以保存为模板（`note_template`）。

**接口结构（实测）**

```json
{
  "kind": "NOTE",
  "title": "…",
  "content": "",
  "tags": [],
  "sortOrder": -1099511627776,
  "status": 0,
  "deleted": 0
}
```

- 笔记与任务共用同一张任务表，用 `kind` 区分：`TEXT`（普通任务）/ `CHECKLIST` / `NOTE`。
- 笔记没有 `startDate / dueDate`，但有 `timeZone`、`reminders`、`tags`。

**结论**：可做。给 `Task` 加 `Kind`，笔记清单过滤 `Kind=NOTE`；详情复用现有备注编辑器，任务 ↔ 笔记互转只需切换 kind 与清空日期。

### 3.4 并列显示

**实测**

- 入口：右键左侧任务模块图标 →「同时显示日历」；再次右键 →「关闭同时显示」。
- 首次开启有引导弹窗：「任务与日历并列显示」，点「开始使用」。
- 布局：左侧当前视图（清单/看板/时间线）+ 中间详情 + 右侧日历；分隔条可拖动。
- 右侧日历保留自己的视图与日期；左侧拖任务到日历可排期。
- 只支持「任务 + 日历」，不支持任意两视图。
- 偏好字段 `desktopSplitView: {showGuide, mtime}`；账户级开关。

**结论**：可做，纯前端。注意我们目前是「满宽单栏 + 详情面板」，要改成「列表 + 详情 + 日历」三栏，移动端退回单栏。

### 3.7 过滤器

**实测菜单与条件**

- 右键过滤器：编辑 / **置顶** / 复制 / 删除。
- 置顶后过滤器进入侧栏顶部图标条（图标 + 名称），不占普通列表空间。
- 新建/编辑过滤器：
  - 「普通 / 高级」两套规则；高级为「条件 + 逻辑 + 条件 + 添加」。
  - 普通条件：清单、日期、优先级（高/中/低/无）、内容包含。
  - 日期：所有、无日期、已过期、重复日期、今天、明天、本周、下周、本月、下月、**时间段（自定义起止）**。
- 视图内排序：分组（清单）、排序（时间 / 创建时间 / 修改时间 / 标题 / 标签 / 优先级）、顺序（从旧到新 / 从新到旧）。
- **没有「按顺序」手动排序**；因此筛选结果不能拖拽排序。

**接口结构（实测）**

```json
{
  "id": "…",
  "name": "…",
  "rule": "",
  "sortOrder": -1099511627776,
  "sortType": "project",
  "viewMode": null,
  "timeline": null,
  "background": null
}
```

- `sortOrder` 控制侧栏顺序；置顶通过偏好里的 `projectPinned` 映射记录（类型 8）。
- `sortType` / `viewMode` 支持每个过滤器记住自己的视图。

**结论**：可做。我们已有 `Order` 和条件 JSON；补 `Pinned`、侧栏拖拽、周/月/时间段、每个过滤器记住视图即可。

### 3.8 清单置顶与清单模板

**实测**

- 右键清单：编辑 / **置顶** / **复制** / 共享 / 归档 / 删除。
- 置顶后清单进入顶部图标条（与置顶过滤器同一区域）。
- 复制清单弹窗：
  - 只复制未完成任务
  - 复制全部任务，保留已完成状态
  - 复制全部任务，不保留已完成状态
  - 关闭 / 确认
- 清单对象 `sortOrder` 控制顺序；`projectPinned` 记录置顶。
- 清单对象字段：`viewMode / timeline / kind / background / inAll / showType / reminderType`。

**结论**：「清单模板」在滴答里就是「复制清单」，不需要独立模板中心。我们已有 `TaskTemplate`，再加快照复制即可；清单置顶只需 `Pinned` 字段。

---

### 3.9 置顶任务

- 任务右键菜单：日期 / 优先级 / 添加子任务 / **置顶** / 放弃 / 移动到 / 标签 / 开始专注 / 创建副本 / 复制链接 / 转换为笔记 / 删除。
- 置顶任务写入 `pinnedTime`；列表顶部单独分组（`pin_tasks`）。
- 快捷键 `Tab+P` 可直接置顶。

**结论**：可做，成本最低。`Task.PinnedAt` + 列表分组 + 右键菜单 + 快捷键。

---

### 3.10 跨筛选结果手动排序

**实测结论**：不支持。

- 过滤器排序只有：时间 / 创建时间 / 修改时间 / 标题 / 标签 / 优先级。
- 没有「按顺序」；「顺序」只是升/降序切换（从旧到新 / 从新到旧）。
- 语言包提示 `当前排序不支持拖动`。

**建议**：从路线图删除该条，不做。
