# Android 客户端视觉与交互规范

本文记录 2026-10 UI 重构后的设计语言。目标不是复制滴答清单，而是借鉴它「大留白、少边框、强层级」的处理方式，建立 caldav-free 自己的纸面式界面。

## 1. 设计原则

1. **纸面分层**：页面是一层层纸张，而不是一堆描边盒子。画布是浅灰，内容是白色圆角面。
2. **一个强调色**：蓝色只用于主操作、当前状态和关键数字；其他信息用墨色与灰色层级表达。
3. **大标题、小元信息**：每个主 Tab 用 30sp 左右的大标题建立入口，说明文字控制在 12sp，不抢视线。
4. **先留白，再分隔**：优先用间距和圆角分组；1px 分隔线只在列表内部使用。
5. **内容优先**：图标为线性 Material 图标，不使用 emoji 充当图标；重要数字使用粗体，次要文本降低对比。
6. **原生交互**：保留 Material 3 的底部导航、FAB、底部 Sheet、Snackbar、对话框和系统返回手势。

## 2. 颜色 Token

| Token | Light | Dark | 用途 |
|---|---|---|---|
| `AppColors.canvas` | `#F5F6F8` | `#0E1015` | 页面画布 |
| `AppColors.surface` | `#FFFFFF` | `#171A22` | 卡片、Sheet |
| `surfaceMuted` | `#F1F3F7` | `#20242E` | 输入框、未选 Chip |
| `primary` | `#3563F0` | `#7F9BFF` | 主操作、当前 Tab、关键数字 |
| `primaryContainer` | `#EAF0FF` | `#23335F` | 选中 Chip、图标底色 |
| `ink` | `#1B1F2A` | `#F2F4F8` | 主文本 |
| `inkSecondary` | `#656D7E` | `#9AA3B2` | 说明、元信息 |
| `line` | `#EDF0F5` | `#2A2F3A` | 列表分隔线 |
| `green` | `#2DCB8A` | 同左 | 完成、同步成功 |
| `orange` | `#FF9F43` | 同左 | 提醒、倒计时节日 |
| `festival` | `#E08A2E` | `#F0A75A` | 农历节日、节气标签 |
| `red` | `#FF5C5C` | 同左 | 逾期、删除 |

`primary` 在白底上的对比度约为 5.0:1，`inkSecondary` 在画布上约为 4.8:1，满足小字号正文的可读性。

## 3. 字体层级

| 角色 | 字号/字重 | 典型用途 |
|---|---|---|
| Display | 48 / 300 | 番茄计时 |
| Headline | 30 / 800 | 任务、日历、习惯、专注、倒数日标题 |
| Title Large | 20 / 700 | Sheet 标题、分组标题 |
| Title Medium | 17 / 700 | 卡片标题 |
| Body Large | 16 / 500 | 任务标题、表单 |
| Body Small | 12.5 / 500 | 元信息、说明 |
| Label | 11–14 / 600 | Chip、Tab、状态 |

- 中文字体走系统字体（PingFang / Noto Sans CJK），避免自带字体包导致包体膨胀。
- 计时器使用 tabular figures，防止每秒跳动时数字宽度变化。
- 不通过斜体、全大写、渐变文字制造层级。

## 4. 形状与间距

- 页面左右边距：20dp；卡片内边距：14–16dp。
- 卡片圆角：20dp；Sheet 顶部圆角：28dp；输入框/按钮：14–16dp。
- FAB：56dp 圆形，右下 20dp。
- 卡片之间：8–12dp；分组之间：24dp。
- 底部导航：62dp 高，5 个 48dp 触控目标，图标 24dp，无文字标签。
- 所有触控目标 ≥48dp；底部导航、关闭按钮、更多菜单通过 `Semantics` 提供可访问名称。

## 5. 页面模式

### 任务

- 顶部：30sp 标题 + 小号同步状态。
- 视图切换：文字 Tab + 2dp 蓝色下划线，不使用分段按钮外框。
- 清单筛选：横向滚动胶囊；选中为浅蓝底，未选中透明。
- 任务卡：白色 18dp 圆角、无边框、24dp 圆形复选框；标题 15.5sp，元信息 12sp；优先级用 3dp 竖条。
- 快速添加：悬浮白色胶囊，带柔和阴影；右侧 40dp 蓝色发送按钮。
- 更多菜单：图标 + 文案，避免纯文字大菜单。

### 习惯

- 标题下显示当前选择日期的完成进度；右上角在非今天时出现「回到今天」。
- 周一至周日日期条：选中日实心主题色圆，今天使用描边圆，未来日期禁用置灰。
- 选择过去日期可查看当天打卡状态，并允许在习惯开始日期之后补卡；服务端会拒绝早于开始日期的补卡。
- 习惯按服务端 section 分组，每个分组一张白色卡片，行间 1px 分隔；每行左侧 48dp 进度环 + 打卡按钮。
- 空状态使用浅蓝圆角图标 + 主标题 + 一句说明 + 主按钮。
- 编辑器使用底部 Sheet，字段为浅灰填充，主按钮固定底部；编辑时保留 sectionId。

### 专注

- 286dp 圆环，轨道 10dp，进度使用圆头弧线。
- 计时 58sp、300 字重，轨道与数字之间留出足够呼吸。
- 时长选择是三个文字胶囊；主按钮为 188×56 胶囊，重置为 52dp 圆形。
- 最近记录使用一张白色卡片，行间分隔线缩进到图标之后。

### 倒数日

- 卡片四角 20dp，白底无描边；左侧 50dp 淡色图标，右侧 34sp 数字。
- 未来显示「30 天」，今天显示「今天」，过去显示「30 天 / 前」。
- 图标使用 Material 线性/填充图标，不直接渲染 emoji。
- 颜色只用于图标底、数字和状态文字；数字颜色自动压暗保证对比度。

### 全局搜索与筛选

- 入口：任务页右上角更多 → 全局搜索；保留当前清单的内联搜索。
- 顶部搜索框自动聚焦，使用浅灰填充圆角胶囊、前置搜索图标和清空按钮；聚焦时只保留细主题色描边，不使用默认下划线。
- 任务页内联搜索与全局搜索共用 `AppSearchField`：填充色、16dp 圆角和聚焦描边都来自主题的 `InputDecorationTheme`（`surfaceMuted` + 主题色细描边），组件本身只负责搜索图标、清空圆点和 15sp 字号。
- 范围 Tab：全部 / 任务 / 日程 / 习惯 / 倒数。
- 任务结果来自本地离线库，输入即筛；日程、习惯、倒数从 Basic Auth 接口拉取，失败时只禁用远程结果，任务搜索仍可用。
- 任务筛选底部 Sheet：状态、优先级、清单、日期（今天/最近7天/逾期/无日期）、标签；支持重置和已选条件摘要。
- 结果按模块分组，每个模块一张白色分组卡；任务可勾选完成，点击任务返回任务列表并打开编辑器。
- 日程/习惯/倒数结果为只读详情 Sheet，避免在搜索页复制编辑逻辑。
- 远程加载使用 8 秒超时并并行请求，离线时不会阻塞任务搜索。

### 看板

- 列不再使用大边框白盒；列头固定在画布上，只有内容卡片和拖放区承担视觉重量。
- 列宽 264dp，列头包含稳定色点、拖拽把手、标题、数量胶囊、添加按钮和更多菜单。
- 卡片为白色 16dp 圆角、轻阴影、无描边；任务标题 14.5sp，标签 11sp。
- 空列使用 116dp 高的浅色拖放区，而不是整列高空白卡片。
- 列头直接添加任务，避免空列底部远距离的“添加任务”按钮。

### 矩阵

- 四个象限改为四张白色圆角卡，仅图标底色和图标颜色区分象限。
- 象限头：28dp 淡色图标、标题 13sp、副标题 10.5sp、数量胶囊。
- 任务行使用 `surfaceContainerLow` 的 12dp 圆角，不再嵌套白色卡片。
- 保留 2×2 等分布局，空象限只显示一行低对比度「暂无任务」。

### 时间线

- 列不再使用整列大色块；今天只在日期头上使用淡主题色胶囊。
- 日视图显示 7 天，周视图 8 周，月视图 3 个月。
- 日期头：标题 14sp + 星期 10.5sp + 数量胶囊；今天标题用主题色。
- 卡片白色 14dp 圆角、轻阴影、无描边；空列使用 96dp 高的拖放区。
- 未日期、逾期、以后列使用同样的紧凑样式，不再与日期列形成两种视觉体系。

### 日历

- 大标题 + 单行视图 Tab；月份切换行保留左右箭头与「今天」。
- 月视图不画单元格边框，日期居中；今天用 32dp 蓝色圆，事件用最多 3 个 5dp 圆点。
- 日视图不再重复日期标题；无安排时使用空状态。
- 事件卡无左侧色条，改用 8dp 色点 + 标题 + 时间/清单元信息。

### 登录

- 画布式登录页，60dp 品牌图标 + 34sp 产品名。
- 表单放在一张白色圆角卡中，输入框浅灰填充，不使用描边。
- 主按钮 52dp，错误信息使用浅红底。

|---|---|---|
| 经典蓝 | `#3563F0` | 5.0:1 |
| 湖水青 | `#2F7D8C` | 4.7:1 |
| 松柏绿 | `#1F7A4D` | 5.3:1 |
| 琥珀 | `#A85A12` | 5.1:1 |
| 玫瑰 | `#C23B5A` | 5.2:1 |
| 暮山紫 | `#6E4BD1` | 5.9:1 |
| 雾灰蓝 | `#4F637A` | 6.2:1 |
| 咖啡 | `#8A5A2B` | 5.9:1 |

- 入口：任务页右上角调色盘，或「更多 → 主题颜色」。
- 选择面板使用 52dp 色圆 + 名称 + 当前勾选，底部 Sheet 28dp 圆角。

## 5.2 日历视图

- 日历视图切换移到右上角菜单，避免 Tab 挤压：
  - 年视图 / 月视图 / 周视图 / 日视图 / 日程
- 进入日历页默认落在「日程」，锚点为今天，即展示最近三日的安排。
- **日程**（默认视图）：连续三天纵向分组，日期头 + 今日胶囊 + 当天条目数；每条日程/任务使用统一 `_EntryTile`。
- **年视图**：3 列 × 4 行迷你月历，每个月是一个 **1px 描边框**（12dp 圆角，`scheme.outline`，底色透出画布 `#F5F6F8`，与 PC `.tw-year-month` 的 `border: 1px var(--tw-border)` + `background: var(--tw-bg)` 一致，**不是填充白卡**）；卡头左侧「N月」、右侧「X 项」（当月事项数，空间不足时计数省略、月份名不收缩），今天实心圆，拥有事项的日期使用主题色加粗；点击日期进入日视图。
- **年视图不滚动**：整屏放 12 个月，4 行用 `Expanded` 平分可用高度，卡内 6 个周行再 `Expanded` 平分剩余空间，格子圆点直径取 `周行高 × 0.94`（上限 18dp），日号用 `FittedBox(scaleDown)` 兜底，因此任何屏宽都不会出现滚动条或裁掉最后一行；右下角为 FAB 预留 `bottomInset`（有可写日历 78dp，否则 12dp）。
- 年视图按月分 4 段请求（每段 ≤ 92 天，服务端上限 120 天），合并事件、任务和来源。
- 月视图在日期下方显示文化标签：节日 > 节气 > 农历日；普通农历日灰色，节日/节气橙色。初一时显示农历月份，如「九月」。
- 标签来自 Basic Auth 农历接口，范围约 6 周；接口失败时回退到「节假日」事件标签。没有标签时保留固定高度，避免行跳动。
- 月视图仍使用无边框网格、今天实心圆和事件圆点；不在格子里堆叠事件标题。

### 周视图 / 日视图（时间网格）

- 一张 20dp 白色圆角卡承载「日期头 + 全天行 + 24 小时网格」；卡内只保留小时横线（`outlineVariant`），**不画列分隔线**，遵循「先留白，再分隔」。
- 日期头画在卡片内部，左侧留出 44dp 时间栏，使每个日期正好位于自己列的上方；今天为实心主题色圆，节日/节气使用 `festival` 色，标签固定高度避免跳动。
- 事件块使用来源色与 `surface` 的 22% 混色底（深色模式自动跟随）：
  - 日视图（列宽约 290dp）：8dp 色点 + 12sp 标题 + 10.5sp 时间。
  - 周视图（列宽约 42dp）：省略色点，只留单行标题；全天事项仍走顶部胶囊行。
- 重叠事件：列宽足够时按列并排；并排后不足 40dp 改为**层叠错位**（每层右移 18%，最多让出 50% 宽度），保证仍可点选；单块不足 30dp 时退化为深一档色条，不放文字。
- 最短事件块 26dp；网格打开时定位到当前时间（当天不在窗口内回到 07:30），红色 now 线每分钟刷新。
- 周/日翻页使用本地基准日 + 无限 `PageView`：滑动只推进本地页码，外部锚点变化（今天、月视图下钻、切换视图）才重新居中；数据窗口在可视范围前后各留一周（周视图）/ 八天（日视图）。
- 日视图当天没有日程与任务时显示「暂无安排」空状态卡，而不是空白网格；空状态卡与网格卡使用同一圆角与外边距。
- 日视图右下角在主「新建日程」FAB 左侧并排一个次级「新建任务」小 FAB（对齐习惯页的 FAB 入口）：`FAB.small`，底色 `surfaceContainerHigh`、图标 `playlist_add_rounded` 取主题色，与实心主 FAB 明显区分；点击后隐藏 FAB，改为底部就地输入条（输入 + 上箭头提交 / 关闭取消），提交走与月视图相同的本地写入路径，任务以所选日期的全天到期日落进收集箱。

## 6. 深色模式

- 深色不是简单反色：画布 `#0E1015`，卡片 `#171A22`，输入 `#20242E`。
- 主色提亮为 `#7F9BFF`，主按钮文字使用深色，保证按钮上的对比度。
- 圆环轨道、分割线、复选框边框在深色下单独调整，避免消失。
- 已在模拟器验证任务页与专注页深色模式。

## 7. 可访问性与适配

- 已验证系统字体缩放 1.3：标题、任务卡、底部导航不截断。
- 支持系统字体缩放、深色模式和任意方向屏幕旋转。
- 宽屏适配断点 `isWideLayout`：`width > height || shortestSide >= 600`（横屏手机与任意方向的平板）。宽屏下底部导航替换为 64dp 图标侧栏 `AppSideNav`，选中项用 `primaryContainer` 填充的圆角胶囊表示，不显示文字标签；竖屏手机仍用底部导航。
- 宽屏任务页为双栏 master-detail：左侧 232dp 清单面板（「视图」组：全部/今天/最近 7 天；「清单」组：按文件夹分组的清单与未读数；底部「管理」入口），右侧保留列表/看板/矩阵/时间线四种视图；竖屏手机仍用顶部「范围」选择行 + 视图作用条。
- 旋转时外壳用 `Row` + 固定子位保持 `IndexedStack` 槽位稳定，页面状态（滚动位置、所选清单、视图）不因方向变化重建；月视图网格按可用高度均分 6 行，任意宽高比下不裁切；空状态在矮视口下改为可滚动居中，避免溢出。
- 底部导航图标无文字，也不挂 Tooltip（长按/悬停弹出的气泡文字与纸面风格冲突且无信息增量）；无障碍名称由 `Semantics(button, selected, label)` 提供。页面内的图标按钮仍保留 Tooltip，因为它们没有可见标签。
- 输入框、按钮、菜单均使用 Material 3 状态层与焦点态。
- 空状态、加载、错误、禁用、删除确认均有对应界面。

## 8. 已知缺口

- 未引入自绘品牌插画；空状态暂时使用 Material 图标 + 色块。
- 尚未实现 Material You 动态取色；主题色目前是本机固定色板。
- 农历标签只显示日/月与节气，不显示宜忌、生肖和闰月详情。
- 年视图不显示农历标签；一次加载全年，数据量很大时仍需分页/缓存。
- 任务编辑器仍是全高 Sheet，后续可改为顶部详情卡 + 可展开字段。
