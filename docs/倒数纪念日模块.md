## 3. 实现说明

- 数据表：`countdown_events`
- 农历转换使用 `github.com/6tail/lunar-go`；`calendar=lunar` 时按 `lunarMonth` / `lunarDay` 计算下一次公历 occurrence
- 日期使用 `YYYYMMDD`，服务端返回 `occurrenceDate`、`days`、`state` 和生日 `age`
- `repeat=none` 的过去日期显示「已经 N 天」
- `repeat=weekend` 与公历节日预设作为 Dida 智能列表/节日预置的本项目近似实现
- `repeat=yearly/monthly/weekly` 自动计算下一次发生日期
- 每年重复日期落在 2 月 29 日时自动收敛到当月最后一天
- 农历事件使用 `calendar=lunar`、`lunarMonth`、`lunarDay`、`lunarLeap`，预设计算下一次 occurrence
- 详情弹窗展示大数字、日期、农历标签、备注、提醒偏移和提醒时间
- 提醒默认在应用时区 09:00 投递，支持每个事件自定义 `reminderTime`；投递记录使用负 `task_id` 和 occurrence/offset key 去重
- 提醒复用站内通知、Web Push、SMTP 和现有退避表
- 当前使用项目自有卡片样式，不保存 Dida 的背景图字段
- `repeat=weekend` 在周六/周日显示「今天」，工作日显示距离本周末的天数
